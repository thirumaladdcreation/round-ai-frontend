# What’s new — RoundsAI demo

Short note for clients. Internal known issues stay off this page.

## What’s new

- **Web and Android demos** you can open without AltStore. **iPhone** via TestFlight when we send an invite (not a raw IPA).
- **Write note from dictation** — speak or paste one update; the scribe cleans and files it into note sections (still review before use).
- **Photo intake** fixes for common phone uploads, with clearer error messages.
- **Look and feel** closer to the clinical prototype (Today tab, colors, navigation).
- **Presentation** gives a clearer next step when facts or today’s plan are still missing.

## How to test in 5 minutes

1. Sign in: `resident@rounds.test` / `ChangeMe-12345`
2. Open a patient → confirm a fact → save **Today’s plan**
3. Try **Write note from dictation** or take a **photo** of a (fictional) chart page

Full walkthrough: [CLIENT_TEST_GUIDE.md](CLIENT_TEST_GUIDE.md)

## Reminder

This build uses **fictional** data for demonstration. It is not cleared for real patient use until your organization completes its own review.
